# Venkatadri Infra website

Static site. No build step.

- `index.html`: the full site (hash routes: `#/`, `#/akshay-golden-gate`, `#/golden-tridhi-farms`, `#/golden-avenue`, `#/gallery`, `#/about`, `#/contact`)
- `assets/img/`: renders, plans and brochure pages

Deploy: import this repo in Vercel as a static project (Framework preset: Other, no build command, output directory: root).
